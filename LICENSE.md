## Why ODbL?

This dataset combines data from multiple source licenses:

| Source | Provider | License |
|---|---|---|
| Öffentliche Brunnen (fountains) | Stadt Graz OGD | CC BY 4.0 |
| Bibliotheken (libraries) | Stadt Graz OGD | CC BY 4.0 |
| Kirchen (churches) | Stadt Graz OGD | CC BY 4.0 |
| Schwimmbäder (swimming pools) | Grazer Freizeitbetriebe GmbH / Stadt Graz OGD | CC BY 4.0 |
| Wasserspielplätze (water playgrounds) | Stadt Graz / Freizeitinfo.at / Mamilade | CC BY 4.0 |
| Sprühnebel-Lanzen (spray mist cooling) | Stadt Graz / Holding Graz | CC BY 4.0 |
| Kulturgebäude (cultural buildings) | Hitzeaktionsplan der Stadt Graz, Version 1.0 | CC BY 4.0 |
| Parks and green spaces | OpenStreetMap contributors | **ODbL 1.0** |

Because OpenStreetMap data is licensed under ODbL with a **share-alike** clause for derivative databases, the combined dataset must be released under ODbL 1.0. This is the most restrictive compatible license that covers all inputs and satisfies the share-alike requirement.
